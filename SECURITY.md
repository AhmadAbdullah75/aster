# Security

See [the security design](docs/security.md) for sessions, ownership, approvals, uploads and isolation.
This project is intended for local use. Review [deployment requirements](docs/deployment.md)
before exposing it to a network.

Never include API keys, passwords, cookies, uploaded private documents or database exports in
issues, screenshots or pull requests. Report vulnerabilities privately to the repository maintainer
using GitHub's private vulnerability reporting if enabled. If no private channel is available,
ask the maintainer for one without posting exploit details or sensitive data publicly.

Rotate any accidentally published secret; deleting it from a later commit is insufficient.
